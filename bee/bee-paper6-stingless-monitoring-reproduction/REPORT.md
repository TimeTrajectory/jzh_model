# 第六篇论文复现结果报告

论文：*Smart Stingless Beehive Internet Based Monitoring System*（Ahmad Kamal et al., 2022）。

## 复现性质

原论文数据、MATLAB 源码和权重未公开。本项目用 BEE22 复现 YOLOv3 系列检测、视频活动监测和采集条件实验。物理高度由明确标注的视场裁切代理实现，不能解释成原农场实验的直接重复。

### 3×3 采集条件代理实验

每个组合固定抽取 20 张测试帧。最佳代理组合为 `30cm + white`，mAP@0.50=0.9141。这里的高度是中央视场裁切因子，背景是框外像素重着色；结果只用于敏感性分析。

## 结论边界

原论文“accuracy 75%”没有公式，不能直接当作 mAP。每分钟 20 次阈值是原型规则，不足以单独判断蜂群健康。
